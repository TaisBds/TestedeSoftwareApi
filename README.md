# 🔌 Teste de Software API

Este projeto consiste no desenvolvimento e teste de uma **API utilizando Node.js**, com foco na validação de requisições através da ferramenta **Postman**.

O objetivo principal foi praticar a criação de rotas, conexão com banco de dados e execução de testes de API, simulando um ambiente real de desenvolvimento backend.

---

## 🚀 Sobre o Projeto

A aplicação implementa uma API simples que permite realizar operações básicas, conectada a um banco de dados, com testes realizados via **Postman** para validação das funcionalidades.

---

## 🛠️ Tecnologias Utilizadas

* 🟢 Node.js
* ⚡ JavaScript
* 🗄️ Banco de Dados (SQL)
* 📬 Postman (Testes de API)
* 📦 NPM

---

## 📂 Estrutura do Projeto

* `.env` → Variáveis de ambiente
* `index.js` → Arquivo principal da aplicação
* `db.js` → Configuração de conexão com o banco de dados
* `api.sql` → Script de criação do banco
* `package.json` → Dependências do projeto

---

## 🔗 Funcionalidades

* ✔️ Criação de rotas (API REST)
* ✔️ Conexão com banco de dados
* ✔️ Execução de queries SQL
* ✔️ Testes de requisições com Postman
* ✔️ Organização de backend básico

## ▶️ Como Executar o Projeto

1. Clone o repositório:

```
git clone https://github.com/TaisBds/TestedeSoftwareApi.git
```

2. Instale as dependências:

```
npm install
```

3. Configure o arquivo `.env` com os dados do banco

4. Execute o projeto:

```
node index.js
```

5. Utilize o **Postman** para testar os endpoints
